# ShopEase – E-Commerce Business Analysis Case Study

## Project Overview

ShopEase is a self-initiated, fictional Business Analysis case study focused on improving the e-commerce order management process.

The project demonstrates requirement gathering and documentation, business process analysis, stakeholder analysis, Agile user story creation, and risk management.

## Problem Statement

The fictional business scenario assumes customers experience unclear payment confirmations, delayed order updates, and difficulties with order cancellations and refund tracking.

## Project Objectives

- Improve the checkout experience.
- Define clear payment confirmation requirements.
- Improve order tracking visibility.
- Support order cancellation requests.
- Provide refund status updates.

## Tools Used

- Microsoft Word – BRD, FRD, Project Charter
- Microsoft Excel – Stakeholder Matrix, User Stories, Acceptance Criteria, Risk Register
- Draw.io – AS-IS and TO-BE Process Flowcharts
- Jira – Epic and User Story Management

## Business Analysis Deliverables

1. Project Charter
2. Business Requirements Document (BRD)
3. Functional Requirements Document (FRD)
4. Stakeholder Analysis
5. AS-IS and TO-BE Process Flowcharts
6. Seven User Stories with Acceptance Criteria
7. Jira Epic and User Stories
8. Risk Register
9. Final Project Summary

## Jira Project

Created an Epic titled "Order Management Improvement" and organized seven user stories covering cart management, checkout totals, payment confirmation, order confirmation, order tracking, cancellation, and refund status.

## Key Learnings

- Business requirements documentation
- Functional requirements analysis
- Stakeholder identification
- AS-IS and TO-BE process mapping
- Agile user stories and acceptance criteria
- Jira work item management
- Risk identification and mitigation planning

## Project Disclaimer

This is a self-initiated fictional Business Analyst case study created for learning and portfolio demonstration purposes. It does not represent a real client engagement, a developed e-commerce website, or implemented software functionality.
